# Echowaves Company Showcase - Project Summary

## Project Overview

A fully responsive React + TypeScript web application showcasing Echowaves Corporation's:
- Company information and mission
- Open-source projects
- NPM packages (expo-cached-image, expo-storage, expo-masonry-layout)
- Real-world applications (WiSaw)
- Contact information and social links
